NeuAI 集成 - 产品需求文档（PRD）

========================
项目概述
========================

本项目将在 Chatwoot 系统中新增一个名为 **NeuAI** 的 AI 集成。

⚠️ **核心原则**：
- 不修改任何现有的 OpenAI 集成相关代码
- 完整复制 OpenAI 的所有代码（前后端），在此基础上创建 NeuAI 集成
- 仅修改配置项和后端调用的 API，其余逻辑、结构和交互保持完全一致
- UI 界面 NeuAI 与 OpenAI 保持一致，但 NeuAI 的代码和入口都是完全一套新的，比如：同时开启的话，按钮是2个，点击后弹出的 Modal 实际也是2个，只是他们现阶段都长得一样

========================
项目目标
========================

1. 增加一个完全独立的 NeuAI 集成
2. NeuAI 提供与 OpenAI 完全一致的功能
3. 配置支持 NeuAI 所需字段
4. 用户在界面上无法区分是使用 OpenAI 还是 NeuAI，除了配置页面
5. OpenAI 和 NeuAI 集成可同时存在，用户可在设置中自由选择使用哪个
6. 方便后续pull上游代码时，新增的 NeuAI 尽量不会产生冲突

========================
实施计划
========================

第一步：识别 OpenAI 集成相关代码
- 分析现有代码库，找出所有与 OpenAI 集成相关的代码文件

第二步：复制并重命名为 NeuAI
- 将上述所有代码复制一份，命名空间替换为 `neuai`
- 示例：
  - `app/services/integrations/neuai/`
  - `composables/useNeuAI.ts`
  - `api/neuai.ts`
- 在配置文件中新增 neuai 项（id: neuai）

第三步：修改配置项和 API 调用
- 替换调用为 NeuAI API 格式：
  POST https://<neuai_url>/api/v1/prediction/{agent_id} HTTP/1.1
   Authorization: Bearer <api_key>
   Content-Type: application/json
   Accept: */*

   {
   "question": "What is artificial intelligence?",
   "form": {
      "title": "Example",
      "count": 1
   },
   "streaming": false,
   "overrideConfig": {
      "sessionId": "user-session-123",
      "temperature": 0.7,
      "maxTokens": 500,
      "vars": {
         "action": <action> // reply_suggestion/summarize/label_suggestion/rephrase ...
      }
   },
   "history": [
      {
         "role": "apiMessage",
         "content": "Hello! I'm an AI assistant. How can I help you today?"
      },
      {
         "role": "userMessage",
         "content": "Hi, my name is Sarah and I'm learning about AI"
      }
   ],
   "uploads": [
      {
         "type": "file",
         "name": "example.png",
         "data": "data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAABgAAAAYCAYAAADgdz34AAABjElEQVRIS+2Vv0oDQRDG",
         "mime": "image/png"
      }
   ],
   "humanInput": {
      "type": "reject",
      "feedback": "Include more emoji"
   }
   }

- NeuAI的配置项为：neuai_url, agent_id, api_key

========================
UI/UX 要求
========================

- 与 OpenAI 完全保持一致
- 复用所有 OpenAI 的组件和样式
- 不新增界面元素或视觉差异

========================
成功标准
========================

| 指标            | 说明                                             |
|-----------------|--------------------------------------------------|
| 功能对等        | NeuAI 实现所有与 OpenAI 相同的功能               |
| 独立性强        | NeuAI 所有代码与 OpenAI 完全隔离                 |
| 配置灵活        | 可独立配置 NeuAI 的相关参数                      |
| 用户无感知差异  | 用户无法通过界面判断当前使用的是哪个服务         |

========================
关键开发原则总结
========================

✅ 不修改任何 OpenAI 代码
✅ 完整复制代码并命名为 neuai
✅ 仅修改配置项和 API 调用逻辑
✅ 保持功能和界面完全一致
✅ 支持 OpenAI 与 NeuAI 共存运行
